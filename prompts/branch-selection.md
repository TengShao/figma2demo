# Branch Selection Prompt

Use this prompt immediately after the user approves the Visual Fidelity Review.

## English

```text
Visual fidelity is approved. What should I do next?

1. Continue with animation and MP4 export.
2. Export a Frontend Mode React/Vite/TypeScript starter from the approved HTML.
3. Do both: finish the MP4 first, then generate the frontend starter.
```
