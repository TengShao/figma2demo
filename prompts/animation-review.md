# Animation Review Prompt

Use this prompt after the animated HTML preview is ready and before any MP4 export.

## English

```text
The animated preview is ready.

Please review the timing, module linkage, cursor behavior, text reveal, pauses, and final hold. Does the animation tell the intended product flow clearly enough to approve MP4 export?
```

## Chinese

```text
动画预览已经准备好。

请检查节奏、模块联动、鼠标行为、文字揭示、停顿和最终停留画面。这个动画是否已经足够清楚地讲出目标产品流程，可以进入 MP4 导出？
```
